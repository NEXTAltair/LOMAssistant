# 活侠传拓展

《活侠传》（Legend of Mortal）的 BepInEx 6 插件。

在原版「活侠传助手」的基础上修复了新版游戏的兼容问题，并加入了一些新功能。

**[▶ B 站功能演示视频](https://www.bilibili.com/video/BV1LZJh6YEUy/)**（3 分钟看完全部功能和安装方法）

**QQ 群：496887060**（使用中遇到问题、有建议，欢迎进群反馈）

## 下载安装

**[⬇ 下载 LOMAssistant.zip](https://github.com/kevinnie2003/LOMAssistant/releases/latest/download/LOMAssistant.zip)**（已包含 BepInEx，解压即用）

**一键安装（推荐）：** 把压缩包解压到任意文件夹，双击里面的 `活侠传拓展安装器.exe`，点「一键安装 / 更新」。安装器会自动找到游戏目录、联网下载最新版（连不上 GitHub 就安装压缩包里自带的版本），并把已知会冲突的旧 Mod 移到 `BepInEx\已停用的Mod`（不删除）。Windows 提示「已保护你的电脑」时，点「更多信息」→「仍要运行」。

**手动安装：**

1. Steam 中右键《活侠传》→ 管理 → 浏览本地文件，打开游戏目录（里面有 `Mortal.exe`）。
2. 把压缩包里的所有内容解压到这个目录，提示同名文件时选择覆盖。
3. 正常启动游戏即可。

之前装过旧版 BepInEx 或原版助手的，同样直接覆盖即可。**请先删除 `BepInEx\plugins` 里的旧版骰子大师、多功能 Mod、赵活系统等同类 Mod**，它们和本 Mod 改的是同一批游戏代码，会导致 Tab 窗口空白等问题。检测到冲突时，游戏启动几秒后会自动弹出 F8 面板，用红字提示是哪个 Mod。卸载：删除游戏目录下的 `winhttp.dll`。

## 功能

### 原版助手已有

- Tab：信息窗口（选项、开关、事件、任务）。本项目改为进游戏时默认收起；拖动右下角可缩放（配置 `TabPanelScale`）
- 对话选项结果直接显示
- 骰子手动选择：点击线路直接选中，跳过逆天判定（本项目加了手柄支持：十字键或左摇杆上下切换线路，A 选中；不切换直接按 A 仍是随机掷骰）
- 讲经堂解锁显示
- 决斗中按 ESC，菜单里有“直接获胜”
- F9：游戏内置的测试/编辑面板（本项目给右侧旗标列加了搜索，见下方）

### 本项目新增 / 修改

- **适配新版游戏**：修复新版游戏中 `CharacterIntroPanel.Show` 新增重载导致的补丁报错。
- **繁体转简体**：原版助手的繁转简函数是空的，信息窗口、选项结果、事件名、旗标等游戏数据一直显示繁体；现在用 Windows 自带的转换接口转成简体。
- **空过**：养成时按 ESC，菜单里有“空过”，消耗 1 次行动、不触发任何事件。主线任务等待中时不可空过。
- **团战直接获胜**：团战中按 ESC 暂停，菜单里有“直接获胜”。
- **手柄支持**：骰子自选线路、空过、团战和决斗的直接获胜都可以用手柄操作（十字键选择，A 确认）。
- **F8 面板**（勾选即时生效，自动保存到配置）：
  - 无限修炼次数（武学点补满）、快速修炼
  - 无限锻造、炼丹次数（锻造点、炼丹点补满）、快速锻造、炼丹
  - 锻造、炼丹不消耗银两
  - 决斗中无敌、决斗中造成伤害为 0
  - 剧情旗标变化提示（默认关）：剧情改动旗标时屏幕上提示，如「【旗标】神兵帖进度  1 → 2」
  - 剧情分支条件提示（默认关）：剧情走到分支判断时，屏幕左侧小窗列出这一轮判断（几秒内接连发生的算一轮）的各分支条件，满足为绿、不满足为红，实际走的那行高亮；有新一轮判断时只显示新的，15 秒没有新判断自动收起（配置 `BranchPanelAutoHide`）；小窗可拖动（位置会记住）、可关闭
  - 以上两项可能剧透，按需打开
  - 游戏倍速：1x / 2x / 3x / 5x（在游戏原本速度上再加速，暂停、剧情快进照常；多周目跳过剧情很方便）
  - 养成行动点：正常 / 不消耗 / 每旬 1 点（**会影响剧情触发，请谨慎使用**，详见下方「养成行动点模式」）
  - 设定天命点（骰子“逆天”消耗的点数，进入存档后显示）
  - 弹珠小游戏中：直接设定总分、得分倍率
  - 存档/读档界面中：给所选存档写备注
- **存档栏位**：手动存档栏位从 20 个增加到 100 个（配置 `SaveSlotCount`）。
- **存档备注**：在存档/读档界面按 F8，可给所选存档写备注，备注以「【备注】」显示在存档栏下方。备注保存为存档旁的 `Save_XXX.dat.note`，随 Steam 云存档同步。从 LOM_SaveSlotExpander 换过来的，首次启动会自动导入它的 `SaveSlotComments.ini` 里的备注（已有备注的栏位跳过，不改动原文件）。存档文件两边通用，不用迁移；不要同时安装两个 Mod。
- **自动存档历史**：养成、剧情、战斗三类自动存档各额外保留 5 个旧档（配置 `AutoSaveHistory`）。读档界面每张自动存档卡片右侧的 ▲/▼ 可以切换到较新/更早的旧档，再点卡片读取。
- **四师兄售卖全部物品**（默认关闭，配置 `EnableShopAllItems = true` 打开）：来自 Jim97 多功能 Mod，活侠传助手整合时去掉了。商店里加入所有没拥有的书籍、杂物、特殊物品；不卖《证类本草》（提前买会导致六月后山事件出 bug）。加进去的商品不写进存档，关掉后商店恢复原样。
- **F9 旗标搜索**：F9 面板底部有搜索栏，按旗标名或中文备注搜（如「孟仙谣」「H040」「神兵帖」），结果分页显示在右侧旗标列，可直接加减。原版只能看到固定的 51 面，游戏里实际有一千多面。「全部」列出所有旗标，「原版」恢复原来的 51 行。**乱改旗标可能让剧情出错，改之前先存档。**
- **选项提示增强**：被锁住的选项（「解锁条件：？？？」「银两不足」这类）后面显示真正的解锁条件和当前值，以及解锁后的效果；满足某个条件就直接接一段剧情的选项，括号里写「若 条件：触发剧情」。
- **输入隔离**：鼠标在 F8 面板、剧情分支小窗、F9 旗标搜索栏上点击时，不会穿透到游戏（推进对话、点到下面的按钮）；在 Mod 的输入框里打字时，不会触发游戏快捷键。
- **导出诊断**：游戏 ESC 菜单 →「环境设定」里有「导出诊断」按钮，一键把日志、配置、插件列表打包到桌面（不含存档），反馈问题时发这个压缩包。Mod 装了不生效、游戏里看不到按钮时，用安装器里的「导出诊断」，它还会检查 winhttp.dll 是不是 64 位、BepInEx 是否完整。
- **剧情分支小窗的透明度**：配置 `PopupOpacity`（0=完全透明，1=不透明，默认 0.5）。
- **随时存档**：剧情的台词、选项、掷骰时和养成界面都能存档，存在独立的 8 个槽位，不占原版存档栏。F6 打开面板选槽位，F5 保存、F7 读取（配置 `AnytimeSaveKey` / `AnytimeLoadKey` / `AnytimePanelKey`）。读档时会快进重演这段剧情到存档的那一句。游戏更新改动了存读档相关代码时会自动停用，等 Mod 适配；不能在战斗中存。

### 养成行动点模式（谨慎使用）

> ⚠️ **这两个模式会改变游戏判断剧情触发时用到的行动点数，可能导致部分剧情、支线不触发或提前触发。** 默认是「正常」。建议只在多周目刷属性时使用，第一次玩、或者想完整体验剧情时请保持「正常」。切换前先手动存一个档，发现问题可以读档并切回「正常」。

游戏里有 40 多处剧情、选项按「剩余行动点」判断是否出现。下面是按游戏数据查到的影响；我们只测试了两个模式的基本流程，这些情况没有逐一在游戏里验证，可能还有没发现的问题。

**不消耗**：行动点扣到剩 1 点后不再扣，一旬里可以一直行动；想进入下一旬，用 ESC「空过」，此时空过会直接结束本旬。

- 没有锁在满值，是因为有剧情（包括主线）要剩 1～2 点才触发，锁满会让主线卡住。
- 停在 1 点后，需要剩 2 点才出现的内容（从铁拳门进入的「小竹回家」、睡丹）就用不了了，要等下一旬的头一两次行动。
- 同一旬里可以反复去同一个地点刷随机事件，事件出现的次数和顺序会跟正常游戏不同，可能影响依赖次数的旗标（例如「被小竹无视次数」）。

**每旬 1 点**：每旬只有 1 次行动，天赋给的额外行动次数也不再生效。

- **从铁拳门进入的「小竹回家」永远触发不了**（要求剩 2 点），睡丹也用不了。
- 原本要在一旬最后一次行动才触发的剧情（包括主线），会提前到旬初触发。
- 有些剧情会让下一旬少行动几次，这个模式下为了防止 0 点卡死，每旬保底 1 点，这类惩罚等于不生效。
- 本旬还有该触发的主线时（例如旬初的唐门会议用掉了唯一的行动点），行动点用完不会进入下一旬，而是补 1 点，避免这一旬的主线被跳过、后面的主线全部卡住。
- 整体行动次数只有原来的三分之一，属性、好感很可能达不到部分剧情和结局的要求。

## 设置

常用开关都在游戏内 F8 面板里。其余设置在首次启动后生成的 `BepInEx\config\LOMAssistant.cfg` 中，改完重启游戏生效。

## 从源码构建

普通玩家直接用上面的下载包即可，这一节只给想改代码的人。

需要 .NET 8 SDK 和已安装 BepInEx 6（Unity.Mono，x64）的游戏目录（编译时直接引用游戏和 BepInEx 的程序集，本仓库不包含任何游戏文件）。

```bash
GAME="D:/Steam/steamapps/common/LegendOfMortal" DOTNET=/path/to/dotnet ./build.sh
```

脚本直接调用 Roslyn（csc）编译，并把 `LOMAssistant.dll` 复制进游戏的 `BepInEx\plugins\LOMAssistant\`。`Newtonsoft.Json.dll` 可以从下载包中获取。

一键安装器（Windows 自带的 .NET Framework 4.5+ 即可运行）：

```bash
DOTNET=/path/to/dotnet ./Installer/build-installer.sh
```
