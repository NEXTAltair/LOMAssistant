# 커피 동반자

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

『활협전』(Legend of Mortal)용 BepInEx 6 플러그인입니다(예전 이름 「活侠传拓展」). 이름 「咖啡伴侣」(커피 친구)는 플레이어들이 서행(瑞杏)에게 붙인 별명 「咖啡」(커피)에서 왔습니다. 瑞杏의 중국어 발음이 중국 커피 체인 「瑞幸(Luckin Coffee)」과 같기 때문입니다. 최신 버전 게임을 지원하며, 스토리 전체 보기, 분기 선택, 수치 편집, 새 저장·불러오기 화면, 수시 저장 등을 추가합니다.

게임 언어를 한국어로 설정하면 이 Mod의 창과 알림도 한국어로 표시됩니다(설정 탭 맨 위 「표시 언어」에서 직접 고를 수도 있습니다). 지금은 자주 쓰는 화면 문구만 번역되어 있고 나머지는 중국어로 나옵니다. 번역이 정확하지 않을 수 있으니, 어색한 번역을 발견하면 [Issues](https://github.com/kevinnie2003/LOMAssistant/issues)로 알려 주세요. 아래 스크린샷은 중국어 화면입니다.

## 설치

압축 파일에 BepInEx가 포함되어 있습니다.

**설치 프로그램(추천)**: 압축을 풀고 `咖啡伴侣安装器.exe`를 실행한 뒤 「一键安装 / 更新」(설치 / 업데이트)를 누르세요.

- 게임 폴더를 자동으로 찾고 최신 버전을 내려받습니다(GitHub에 연결되지 않으면 동봉된 버전을 설치).
- 충돌하는 옛 Mod는 `BepInEx\已停用的Mod`로 옮깁니다(삭제하지 않음). 설정은 그대로 유지됩니다.
- 업데이트할 때는 다시 실행하면 됩니다. Windows가 「PC 보호」 경고를 띄우면 「추가 정보」 → 「실행」을 누르세요.

**수동 설치**: Steam에서 『활협전』 우클릭 → 관리 → 로컬 파일 보기를 누르고, 압축 파일의 내용을 전부 게임 폴더에 덮어써서 풀어 주세요.

**제거**: 설치 프로그램에서 「卸载本 Mod」(제거)를 누르세요. 저장 파일에는 영향이 없습니다.

## 단축키

| 키 | 기능 |
|---|---|
| F8 | 설정. 저장 화면에서는 선택한 저장에 메모 작성 |
| F5 / F7 | 수시 저장: 새로 저장 / 최근 것 불러오기 |
| F6 | 「수시 저장」 탭 (목록, 불러오기, 메모, 삭제) |
| F2 | 읽은 대사 빨리 넘기기 (Ctrl을 계속 누른 것과 같음). 안 읽은 대사에서 멈춤 |
| F4 | 판정 전으로 되돌리기 |
| F9 | 수치 탭 |
| Tab | 咖啡伴侣 창 |
| 패드 L3 | 咖啡伴侣 창 열기/닫기 (왼쪽 스틱 누르기, 설정 탭에서 R3이나 LB+RB로 변경 가능) |
| ESC | 게임 메뉴에 「턴 넘기기」 「즉시 승리」 「진단 내보내기」 추가 |

단축키는 설정 탭에서 바꿀 수 있습니다.

## 기능

### 스토리

- **스토리 회고** (Tab):
  - **지금**: 현재 장면의 선택지·주사위 결과, 이후 대사를 읽었는지, 분기 조건, 현재 장소의 랜덤 이벤트(다음에 일어날 것을 고를 수 있음), 현재 임무와 부족한 조건.
  - **루트 맵**: 메인 스토리 전체를 달력 순서로 늘어놓고 서브는 아래에 표시합니다. 정거장을 누르면 언제·어디서·어떤 조건으로 발생하는지 볼 수 있고, 임무 이름·장소·대사로 검색할 수 있습니다.
  - **스토리 맵**: 임무 하나를 흐름도로 그려 각 갈래의 선택지·조건과 수치 변화를 보여 줍니다.
  - **분기 저장**: 중요한 장면이 시작될 때 자동 저장하고 「여기서 다시 하기」로 언제든 다시 해 볼 수 있습니다. 저장 폴더에 `LOMStory_`로 시작하는 파일로 저장되며 Steam 클라우드로 동기화됩니다.
  - **엔딩 일람**: 엔딩(한청서), 사망(생사부), 업적(풍운사). 달성하지 못한 것은 가는 방법을 알려 줍니다.
- **주사위 직접 선택**: 주사위 판정 때 갈래를 누르면 그 결과가 됩니다.
- **선택지 결과**: 대화 선택지에 고르면 무엇이 바뀌는지 표시합니다. 잠긴 선택지에는 실제 해금 조건을 보여 주고 「원클릭 해제」로 조건을 채울 수 있습니다.
- **분기 창** (기본 끔, 스포일러 주의): 분기 조건을 표시하고 충족하면 초록색.
- **UI 숨기고 CG 보기**: 스토리 중 마우스 오른쪽 클릭.
- **랜덤 이벤트 선택** (기본 끔): 일·산책 같은 랜덤 이벤트를 골라서 발생시킵니다.
- **플래그 변화 알림** (기본 끔, 스포일러 주의).

### 저장

- **수시 저장**: 대사·선택지·주사위 때나 육성 화면에서 F5를 누르면 저장됩니다(게임 슬롯을 쓰지 않음, 최대 100개, 변경 가능). F7은 최근 것 불러오기, F6은 목록.
- **판정 전으로 되돌리기** (F4): 판정 바로 앞 대사로 돌아가 F9로 수치를 조정한 뒤 진행하면 새 수치로 다시 판정합니다.
- **새 저장·불러오기 화면** (기본 켬): 연인 얼굴, 게임 날짜, 저장 시각, 메모, 불러온 뒤 나올 대사. 수동 저장과 자동 저장은 다른 페이지(게임패드는 LB / RB).
- **수동 저장 100 슬롯** (원래 20), **저장 메모**, 자동 저장 **이전 기록 5개씩 보관**.

### 육성과 전투

- 설정 탭: 능력치 한계 돌파, 수련 횟수 무제한, 단조·연단 무제한, 결투 아군 무적, 단체전 피해 없음, 필살기 쿨타임 없음, 게임 배속 1x/2x/3x/5x, 핀볼 점수.
- ESC 메뉴의 「턴 넘기기」와 「즉시 승리」.
- **진행 가속**: 장면 전환, 불러오기, 빨리 넘기기가 빨라집니다.
- **행동력**: 보통 / 소모 없음 / 순당 N회. 스토리 발생에 영향을 줄 수 있으니 자주 저장하세요.
- **넷째 사형 상점에서 모든 아이템·무공 판매** (기본 끔).

### 수치 탭 (F9)

능력치, 무공, 문파, 호감, 천부, 수련 점수, 시설, 서적, 아이템, 칭호, 모든 플래그를 편집할 수 있습니다. 함부로 바꾸면 스토리가 꼬일 수 있으니 먼저 저장하세요.

### 기타

- **게임패드**: 咖啡伴侣 창은 패드만으로 조작할 수 있습니다(검색창·숫자 입력칸에 입력할 때는 키보드가 필요). 왼쪽 스틱을 눌러(L3) 창을 열고, 창 안에서는 왼쪽 스틱이나 방향 패드로 포인터 이동, A로 클릭, 오른쪽 스틱으로 스크롤, LB / RB로 탭 전환, B로 닫기입니다. 창이 열려 있는 동안 게임은 패드에 반응하지 않습니다. PS·Switch 컨트롤러에서는 각각의 버튼 이름(× / ○, L1 / R1 등)으로 안내합니다.
- **다국어**: 게임 언어(간체·번체·한국어)를 따라 표시하고, 일본어 패치가 있으면 일본어로 표시합니다.
- **진단 내보내기**: ESC → 환경 설정 → 「진단 내보내기」로 로그·설정·플러그인 목록을 바탕화면에 묶어 줍니다(저장 파일 제외).
- **충돌 감지**: 충돌하는 옛 Mod가 있으면 설정 탭을 열어 알려 줍니다.

## 자주 묻는 질문

**버그를 만나면?** 먼저 설치 프로그램을 다시 실행해 최신 버전인지 확인하세요. 그래도 안 되면 진단을 내보내서 [Issues](https://github.com/kevinnie2003/LOMAssistant/issues)에 상황과 함께 올려 주세요.

**설치했는데 아무 변화가 없다면?** 트레이에서 Steam을 완전히 종료한 뒤 게임을 다시 실행하세요.

**Linux / Steam Deck?** 수동 설치 후 Steam 실행 옵션에 `WINEDLLOVERRIDES="winhttp=n,b" %command%`를 추가하세요.

## 설정

모든 설정은 창의 설정 탭(F8)에 있고, 바꾸면 바로 저장됩니다. 이름에 마우스를 올리면 설명이 나옵니다. `BepInEx\config\LOMAssistant.cfg`에도 저장됩니다.
