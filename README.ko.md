# 커피 동반자

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

『활협전』(Legend of Mortal)용 BepInEx 6 플러그인입니다. 이름 「咖啡伴侣」(커피 친구)는 플레이어들이 서행(瑞杏)에게 붙인 별명 「咖啡」(커피)에서 왔습니다. 瑞杏의 중국어 발음이 중국 커피 체인 「瑞幸(Luckin Coffee)」과 같기 때문입니다. 최신 버전 게임을 지원하며, 스토리 전체 보기, 분기 선택, 수치 편집, 새 저장·불러오기 화면, 수시 저장 등을 추가합니다.

게임 언어를 한국어로 설정하면 이 Mod의 창과 알림도 한국어로 표시됩니다(설정 탭 맨 위 「표시 언어」에서 직접 고를 수도 있습니다). 지금은 자주 쓰는 화면 문구만 번역되어 있고 나머지는 중국어로 나옵니다. 번역이 정확하지 않을 수 있으니, 어색한 번역을 발견하면 [Issues](https://github.com/kevinnie2003/LOMAssistant/issues)로 알려 주세요. 아래 스크린샷은 중국어 화면입니다.

## 설치

압축 파일에 BepInEx가 들어 있습니다.

**설치 프로그램(추천)**: 압축을 풀고 `咖啡伴侣安装器.exe`를 실행한 뒤 「설치 / 업데이트」를 누르세요. 게임 폴더를 자동으로 찾아 최신 버전을 내려받고(GitHub에 연결되지 않으면 동봉된 버전을 설치), 충돌하는 옛 Mod는 `BepInEx\已停用的Mod`로 옮깁니다(삭제하지 않음). 업데이트할 때는 다시 실행하면 됩니다. 설치 프로그램은 Windows 표시 언어에 맞춰 표시됩니다.

<img src="media/installer.webp" width="640" alt="설치 프로그램: 게임 폴더, 설치된 버전과 설치할 버전, 업데이트 내용, 설치 / 업데이트, 진단 내보내기, 제거">

**수동 설치**: Steam에서 『활협전』을 우클릭 → 관리 → 로컬 파일 보기에서, 압축 파일의 내용을 모두 게임 폴더에 덮어쓰며 풀어 주세요. 먼저 `BepInEx\plugins`에서 같은 종류의 옛 Mod(骰子大师, 多功能 Mod, 赵活系统)를 지우세요.

**제거**: 설치 프로그램에서 「제거」를 누르세요. 저장 데이터에는 영향이 없습니다.

## 단축키

| 키 | 기능 |
|---|---|
| Tab | 커피 동반자 창(지금, 루트 맵, 스토리 맵, 분기 저장, 수시 저장, 엔딩 일람, 수치, 설정) |
| F8 | 설정. 저장 화면에서는 고른 저장에 메모 쓰기 |
| F9 | 수치 탭 |
| F5 / F7 / F6 | 수시 저장: 저장 / 최근 것 불러오기 / 목록 |
| F2 | 읽은 대사 빨리 넘기기. 안 읽은 대사에서 멈춤 |
| F4 | 판정 전으로 되돌리기 |
| 우클릭 | UI 숨기고 CG 보기 |
| 게임패드 L3 | 커피 동반자 창 열기/닫기 |
| ESC | 게임 메뉴에 「턴 넘기기」「즉시 승리」「진단 내보내기」 추가 |

키는 설정 탭 「단축키」에서 바꾸거나 해제할 수 있습니다.

## 기능

### 스토리 회고 (Tab)

- **지금**: 지금 장면의 선택지·주사위 결과, 분기 조건, 이후 대사를 읽었는지. 현재 장소의 랜덤 이벤트와 확률(다음에 일어날 것을 고를 수 있음). 진행 중인 메인·서브 퀘스트를 어디서 발생시키는지, 무엇이 부족한지.

  <img src="media/story-now.webp" width="640" alt="지금: 이 장면의 선택지를 선택별로 묶고, 수치 증가는 초록, 감소는 빨강. 진행 중인 퀘스트">

- **루트 맵**: 메인 스토리 전체를 달력 순서로 정거장처럼 늘어놓고, 분기는 다른 줄로, 서브는 아래에 표시합니다. 체크는 이번 회차에 지나온 곳입니다. 정거장을 누르면 언제·어디서·어떤 조건으로 발생하는지 볼 수 있고, 임무 이름·장소·대사·플래그로 검색할 수 있으며, 플래그는 어느 스토리에서 바뀌고 판정되는지 보여 줍니다.

  <img src="media/story-route.webp" width="640" alt="루트 맵: 메인 스토리를 달력의 정거장으로, 서브 퀘스트는 아래에">

- **스토리 맵**: 임무 하나를 흐름도로 그리고, 길마다 필요한 선택지·조건을 표시합니다.

  <img src="media/story-flow.webp" width="640" alt="스토리 맵: 장면 사이의 선택지, 조건, 가는 곳">

- **분기 저장**: 임무 시작이나 중요한 선택지에서 자동으로 저장하고, 「从这里重玩」으로 돌아가 다른 길을 시험할 수 있습니다. 저장마다 따로 관리하며, 저장 슬롯을 쓰지 않고 Steam 클라우드로 동기화됩니다.

  <img src="media/story-nodes.webp" width="640" alt="분기 저장: 기록한 장면을 날짜별로 보여 주고 다시 하기·삭제">

- **엔딩 일람**: 엔딩·사망·업적의 달성 현황과 도감 번호. 달성하지 못한 것은 가는 방법을 보여 줍니다.

  <img src="media/story-endings.webp" width="640" alt="엔딩 일람: 엔딩·사망·업적, 달성·미달성으로 거르기">

### 스토리 보조

- **주사위 선택**: 주사위 판정에서 선을 누르면 그 결과가 됩니다.
- **선택지 결과**: 대화 선택지와 주사위 선에 고르면 무엇이 바뀌는지 표시합니다. 잠긴 선택지에는 실제 해금 조건을 보여 주고 「원클릭 해제」로 조건을 채울 수 있습니다. 설정의 「선택지 결과」에서 항상 표시 / 마우스를 올릴 때만 표시(안 보면 스포일러 없음) / 표시 안 함을 고를 수 있습니다.

  <img src="media/option-hint.webp" width="640" alt="선택지 뒤에 결과와 해금 조건 표시">

- **랜덤 이벤트 선택** (기본 끔): 일·산책 등에서 일어날 이벤트를 고르거나 원래 확률로 뽑습니다. 난수로 정해지는 분기(수련 중 小梅 호감도 확률로 달리기에 끌려가는 등)도 길을 고를 수 있습니다. 이벤트·길마다 「항상」「안 나옴」을 설정할 수 있고, 기억되어 이 기능을 꺼도 적용됩니다.

  <img src="media/event-picker.webp" width="480" alt="랜덤 이벤트 선택: 발생할 수 있는 이벤트, 확률, 변화">

- **지도 건물 이벤트 안내**: 육성 지도에서 건물에 마우스를 올리면 그곳의 메인·서브 퀘스트(발생 가능 여부, 조건)와 랜덤 이벤트 확률을 보여 줍니다. 지금 발생할 수 있고 아직 안 한 퀘스트가 있는 건물은 계속 빛납니다.
- **분기 창** (기본 끔, 스포일러 주의): 분기 판정 때마다 화면 왼쪽에 각 분기 조건을 표시합니다. 충족은 초록, 미충족은 빨강.

  <img src="media/branch-panel.webp" width="480" alt="분기 창: 충족한 조건은 초록, 못 한 조건은 빨강">

- **플래그 변화 알림** (기본 끔, 스포일러 주의): 스토리가 플래그를 바꾸면 화면에 알림. 표시 시간은 바꿀 수 있습니다.
- **대화 기록의 판정 기록**: 지나간 판정·조건·당시 수치를 대화 기록에 남깁니다.
- **UI 숨기고 CG 보기**: 스토리 중 우클릭하면 배경·CG·초상화만 남습니다. 다시 누르면 돌아옵니다.

### 저장

- **수시 저장**: 대사·선택지·주사위 때와 육성 화면에서 저장할 수 있고, 게임 저장 슬롯을 쓰지 않습니다. F5 저장, F7 최근 것 불러오기, F6 목록(메모, 그때의 대사). 최대 100개. 전투 중에는 불가.
- **판정 전으로 되돌리기**: 판정을 본 뒤 F4로 그 앞 대사로 돌아가 F9로 수치를 고친 다음 진행하면 다시 판정합니다.

  <img src="media/anytime-save.webp" width="640" alt="수시 저장 탭: 목록, 불러오기, 메모, 삭제">

- **새 저장·불러오기 화면** (원래 화면으로 되돌릴 수 있음): 연인 얼굴, 날짜, 메모가 있는 목록과, 연인 초상화와 불러온 뒤 첫 대사를 보여 주는 상세 칸. 수동 저장과 자동 저장은 다른 페이지.

  <img src="media/save-browser.webp" width="640" alt="새 불러오기 화면: 왼쪽에 연인 얼굴과 메모가 있는 저장 목록, 오른쪽에 초상화와 불러온 뒤의 대사">

- **슬롯 추가**: 수동 저장 100칸(원래 20), 전기 슬롯 5페이지(원래 1페이지 12칸), 자동 저장은 종류마다 이전 기록 5개씩 보관.
- **저장 메모**: Steam 클라우드로 동기화. LOM_SaveSlotExpander의 메모도 가져옵니다.

### 육성과 전투

설정 탭(F8) 「육성」「전투」 그룹의 스위치:

- 게임 배속 1x / 2x / 3x / 5x
- 행동력: 보통 / 소모 안 함 / 순마다 N회
  > ⚠️ 뒤의 두 가지는 스토리가 발생하지 않거나 앞당겨질 수 있고, 중요한 메인 퀘스트가 막힐 수도 있습니다. 자주 저장하세요.
- 능력치 한계 돌파, 수련 횟수 무제한, 단조·연단 무제한에 은량 불필요
- 결투에서 무적, 적 피해 없음. 단체전에서 아군 피해 없음, 절초 쿨타임 없음
- 결투 적 행동 예측(기본 끔): 적의 예정 행동 표시. 창은 이동·크기 조절 가능
- 핀볼 총점과 배율. 넷째 사형이 모든 아이템 판매(기본 끔)

그 밖에:

- **턴 넘기기**: 육성 화면이나 유학 지도의 ESC 메뉴에서. 행동 1회를 쓰고 이벤트는 일어나지 않습니다.
- **즉시 승리**: 결투·단체전 ESC 메뉴에서.
- **진행 가속**: 장면 전환, 불러오기, 빨리 넘기기가 빨라지고, 수치 변화 뒤 대기가 짧아지며 결투 턴 사이 대기도 없어집니다.
- **스킬 목록 나누기**: 전투 중 아군 스킬 목록이 길면 여러 열로 나눕니다.

### 수치 탭 (F9)

능력치, 무공, 문파, 호감(모든 인물), 천부, 수련·단조·연단 포인트, 시설, 서적, 아이템, 플래그를 한 페이지에서 늘리고 줄이거나 바로 설정할 수 있고, 이름·ID·설명으로 검색할 수 있습니다.

- **서적·아이템**: 개수를 바로 설정. 상점에서 산 것처럼 퀘스트가 진행됩니다.
- **연인**은 이름으로 표시. **심상 잠금**을 걸면 스토리와 선택지로 심상이 바뀌지 않습니다.
- **칭호**: 모든 칭호에서 고르거나 직접 쓸 수 있습니다.
- **플래그**: 천 개가 넘는 플래그를 문파 호감·인물·육도·스토리 등으로 분류.
- **역추적**: 플래그·서적·아이템 이름을 누르면 어느 스토리에서 바뀌고 판정되는지 보여 주고, 스토리 맵으로 이동할 수 있습니다.

<img src="media/stats.webp" width="640" alt="수치 탭: 능력치, 무공, 문파, 칭호, 호감 등을 그룹별로 편집">

수치나 플래그를 함부로 바꾸면 스토리가 꼬일 수 있습니다. 먼저 저장하세요.

### 기타

- **게임패드**: 창 전체를 게임패드로 조작할 수 있습니다(L3로 열기/닫기, 왼쪽 스틱으로 포인터, A로 클릭, LB / RB로 탭 전환). 주사위, 턴 넘기기, 랜덤 이벤트 선택도 지원.
- **화면**: 다크 모드, 본명조 또는 微软雅黑 글꼴, 창·작은 창·안내 상자 불투명도 각각 조절, 대사 글자 확대.
- **언어**: 간체·번체·한국어는 게임 언어를 따르고, [일본어 패치](https://dlaqe2334.github.io/LOM-JPMOD/)가 있으면 일본어로 표시합니다. 설정에서도 고를 수 있습니다.
- **진단 내보내기**: ESC → 「환경 설정」 → 「진단 내보내기」로 로그와 설정을 바탕 화면에 묶습니다(저장 데이터 제외). 설치 프로그램에도 있습니다.
- **충돌 감지**: 충돌하는 옛 Mod가 있으면 설정 탭 맨 위에 표시. 다른 Mod와 같은 키를 쓰면 이 Mod 쪽이 양보합니다.
- **전기 내보내기**: 「상태 → 전기」에서 이번 회차의 전기를 언제든 txt로 내보낼 수 있습니다.
- **빠른 시작**: 타이틀 애니메이션을 빠르게 하고, 설치 프로그램으로 시작 로고를 건너뛸 수 있습니다.
- **그 밖에**: 강경당 전부 해금 표시, 다른 창으로 바꿔도 게임이 멈추지 않음, 창 오른쪽 위에서 버전별 업데이트 내용과 새 버전 알림.

## 자주 묻는 질문

**버그를 만나면?** 먼저 설치 프로그램을 다시 실행해 최신 버전인지 확인하세요. 그래도 안 되면 진단을 내보내 [Issues](https://github.com/kevinnie2003/LOMAssistant/issues)에 상황과 함께 올려 주세요.

**설치했는데 반응이 없다면?** 트레이에서 Steam을 완전히 종료한 뒤 게임을 다시 실행하세요. 그래도 안 되면 설치 프로그램의 「진단 내보내기」를 쓰세요.

**게임 경로에 한글 등이 들어 있다면?** 영어가 아닌 문자가 있는 경로에서는 BepInEx가 로드되지 않습니다. 게임 폴더를 영문·숫자만 있는 경로로 옮기고(Steam에서 게임 우클릭 → 속성 → 설치된 파일 → 설치 폴더 이동), 설치 프로그램을 다시 실행하세요.

**선택지 결과가 안 나오고 주사위를 못 고른다면?** 같은 종류의 옛 Mod가 깔려 있습니다. 설치 프로그램은 자동으로 처리하며, 수동 설치라면 `BepInEx\plugins`에서 옛 Mod를 지우세요.

**邪神认知污染ON·剧情随行과 같이 쓸 수 있나요?** 네. 邪神认知污染ON은 「1_必装_插件」만 깔고 「2_只有没装过BepInEx才装」는 깔지 마세요(깔았다면 이 Mod의 설치 프로그램을 다시 실행). 겹치는 키는 이 Mod 쪽이 양보하니 「단축키」에서 다른 키를 지정하세요.

**Linux / Steam Deck?** 수동으로 설치하고 Steam 실행 옵션에 `WINEDLLOVERRIDES="winhttp=n,b" %command%`를 추가하세요.
