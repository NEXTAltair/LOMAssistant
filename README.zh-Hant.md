# 咖啡伴侶

[简体中文](README.md) · **繁體中文** · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

## 安裝

壓縮包已包含 BepInEx，不用另外下載。

**一鍵安裝（推薦）**：解壓後雙擊 `咖啡伴侣安装器.exe`，點「一鍵安裝 / 更新」。

- 自動找到遊戲資料夾，連線下載最新版（連不上 GitHub 就安裝壓縮包裡自帶的版本）。
- 已知會衝突的舊 Mod 移到 `BepInEx\已停用的Mod`，不刪除；不改動你的設定。
- 以後更新再執行一次即可。Windows 提示「已保護你的電腦」時，點「其他資訊」→「仍要執行」。

<img src="media/installer.webp" width="640" alt="安裝器：遊戲資料夾、已安裝和將安裝的版本、更新內容，一鍵安裝 / 更新、匯出診斷、卸載">

**手動安裝**：Steam 中右鍵《活俠傳》→ 管理 → 瀏覽本機檔案，把壓縮包裡的所有內容解壓到遊戲資料夾，提示同名檔案時選覆蓋。先刪掉 `BepInEx\plugins` 裡的舊版骰子大師、多功能 Mod、趙活系統等同類 Mod，它們和本 Mod 改的是同一批遊戲程式碼。

**卸載**：執行安裝器，點「卸載本 Mod」。會刪掉本 Mod 和它的設定、恢復開頭 Logo；沒有別的 Mod 了就連 BepInEx 一起刪，遊戲資料夾回到沒裝 Mod 的樣子。存檔不受影響。

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| F8 | 設定（所有開關、倍速、行動點、熱鍵）；存檔介面裡給所選存檔寫備註 |
| F5 / F7 | 隨時存檔：存一個新檔 / 讀最近的一個 |
| F6 | 咖啡伴侶視窗的「隨時存檔」頁（全部隨時存檔、讀取、備註、刪除） |
| F2 | 一鍵快進：一直跳過讀過的對話（像一直按著 Ctrl），再按一下停；碰到沒讀過的對話自己停 |
| F4 | 回退到劇情判定前 |
| F9 | 數值面板（屬性、好感、門派、天賦、旗標） |
| Tab | 咖啡伴侶視窗（此刻、路線圖、劇情圖、節點存檔、隨時存檔、結局速查、數值、設定） |
| 手把 L3 | 開關咖啡伴侶視窗（按下左搖桿；設定頁可改成 R3 或 LB+RB） |
| ESC | 遊戲選單裡加了「空過」「直接獲勝」「匯出診斷」 |

按鍵都可以在視窗的「設定」頁「熱鍵」裡改，也都能設成「不綁定」（打開視窗的 Tab 除外）。

## 功能

### 劇情輔助

- **劇情回顧**（Tab 打開咖啡伴侶視窗）：看清整個遊戲的劇情怎麼走，還能回到之前的劇情重玩。分五頁：
  - **此刻**：打開就是這一頁，只講眼下。這一段劇情的每個選項、轉盤會有什麼結果（完整顯示，不截斷），選了以後的劇情讀沒讀過，和分支要什麼條件；點右上角「在劇情圖裡看」直接打開這一段所在任務的劇情圖，看後續怎麼發展；當前地點的隨機事件、概率、條件和結果，滿足條件的可以點「下次觸發這個」直接選定；現在的主線和支線任務（主線排在最前），滿足條件的寫明去哪裡觸發，沒滿足的寫出還差什麼。

    <img src="media/story-now.webp" width="640" alt="此刻：這一段的選項按第幾次選擇分組，數值變化加為綠、減為紅；現在的任務">

  - **路線圖**：整個遊戲的主線按時間從左到右排開，一站是一個主線任務。路線分岔的地方會分成上下幾條線，支線列在下面。
    - 圓圈越黑，說明這段對白讀得越多；打勾的是這一局走過的；蓋紅色「今」字的是你現在所在的主線。
    - 點一站，可以看它什麼時候、在哪觸發，需要什麼條件（還會寫出你現在的數值），以及站裡有哪些岔路、怎麼進去。
    - 搜尋框能搜任務名、地點和台詞，點搜尋結果會跳到對應的劇情。
    - 按住滑鼠拖動地圖，Shift + 滾輪左右移動，Ctrl + 滾輪以滑鼠位置為中心縮放。

    <img src="media/story-route.webp" width="640" alt="路線圖：主線按日曆排成站點，支線掛在下面">

  - **劇情圖**：選一個任務，把它的劇情畫成流程圖。每個方塊是一段劇情，方塊之間的線上寫著要選哪個選項、滿足什麼條件才會走過去。點方塊可以看去每個方向的條件，以及路上屬性會怎麼變。

    <img src="media/story-flow.webp" width="640" alt="劇情圖：劇情段之間的選項、條件和去處">

  - **節點存檔**：劇情走到關鍵的地方（任務、事件的開頭，或者會通向不同劇情、結局的選項）時，自動存下這段劇情開頭的進度。
    - 點「從這裡重玩」並確認，就能回到那段劇情的開頭重新玩，想試另一條路很方便。
    - 每個存檔各收錄各的，不同存檔、不同路線互不干擾；不占用、也不改動你的手動存檔。
    - 這些進度放在遊戲存檔資料夾裡（`LOMStory_` 開頭），會跟著 Steam 雲同步；不想要了，刪掉這些檔案就行。

    <img src="media/story-nodes.webp" width="640" alt="節點存檔：按日期列出收錄的劇情段，可重玩、刪除">

  - **結局速查**：分結局（汗青書）、死亡（生死簿）、成就（風雲史）三類，每類顯示達成數；可以只看已達成或未達成。遊戲圖鑑裡的編號也標出來（汗青書「結局N」、生死簿「N.」），可以按編號搜；預設按編號排，旁邊能切換「按時間」（劇情裡最早能觸發的時間）。沒達成的寫著要怎麼走到，成就還列出獎勵。

    <img src="media/story-endings.webp" width="640" alt="結局速查：結局、死亡、成就三類，可只看已達成或未達成">

  - 路線圖、劇情圖、結局速查要先讀一遍全部劇本：進了養成地圖會在後台提前讀好；還沒讀完就打開的話，要等一兩秒。

- **分支自選**：擲骰判定時，點擊任意一條線路直接選中那個結果，不用碰運氣。不點直接按開始仍是隨機。
- **選項結果**：對話選項後面直接顯示選了會有什麼變化。

  <img src="media/option-hint.webp" width="640" alt="選項後面顯示結果和解鎖條件">

- **選項解鎖條件**：被鎖住的選項（「解鎖條件：？？？」「銀兩不足」這類）顯示真正的解鎖條件和當前值；滿足條件就接一段劇情的選項，括號裡寫「若 條件：觸發劇情」。
- **一鍵設定**（設定頁可關，預設開）：被鎖住的選項旁有「一鍵設定」，把沒滿足的解鎖條件直接改到滿足，選項當場解鎖。
- **劇情分支小窗**（設定頁開啟，預設關，可能劇透）：劇情走到分支判斷時，螢幕左側列出各分支條件，滿足為綠、不滿足為紅，實際走的那行高亮。小窗可拖動、可關閉，15 秒沒有新判斷自動收起。

  <img src="media/branch-panel.webp" width="480" alt="劇情分支小窗：滿足為綠，不滿足為紅">

- **隱藏介面看 CG**：劇情裡按滑鼠右鍵，對話框、標題等文字介面和本 Mod 的視窗都藏起來，只留背景、CG 和立繪，方便截圖；再按一次恢復。習慣用右鍵做別的事，可以在設定頁「熱鍵」裡改成鍵盤上的鍵或滑鼠中鍵；不想要就設成「不綁定」。
- **回想裡的判定記錄**：劇情經過的判定點、觸發條件和當前值會記進回想（對話記錄）裡，可以翻回去看。
- **隨機事件自選**（設定頁開啟，預設關）：工作、閒逛這類隨機事件，劇情走到抽事件那一步時先停下，列出這次滿足條件的事件和各自概率、會帶來的變化，選一個就觸發它，也可以選「隨機」按原本概率抽。只有一個能觸發時不停。可以用滑鼠點，也可以用方向鍵、數字鍵、Enter或手把十字鍵加確認鍵。

  <img src="media/event-picker.webp" width="480" alt="隨機事件自選：列出可觸發的事件、概率和變化">

- **地圖建築事件提示**（預設開，設定頁「養成」可關）：養成地圖上滑鼠停在建築上，列出這裡的主線、支線（現在能不能觸發、時間、條件，滿足為綠、不滿足為紅，帶當前值）和點進去可能抽到的隨機事件、概率；不在時間內的任務折成一行。有現在就能觸發、這一局還沒走過的主線或支線的建築會一直亮著（隨機事件不算）。
- **旗標變化提示**（設定頁開啟，預設關，可能劇透）：劇情改動旗標時在螢幕上提示，如「【旗標】神兵帖進度 1 → 2」。提示預設停留 4 秒（按真實時間，開倍速也看得清），可在「設定」頁改。

### 存檔

- **隨時存檔**：劇情的台詞、選項、擲骰時，以及養成介面，都能存檔。每次按 F5 存一個新檔（存在存檔目錄下的 `AnytimeSave`），不占原版存檔欄，最多保留 100 個（設定頁可改），超過自動刪最舊的。F7 讀最近的一個；F6 打開咖啡伴侶視窗的「隨時存檔」頁，列出全部隨時存檔，可以讀取、寫備註、刪除，滑鼠停在一個存檔上能看到當時的遊戲日期、所在任務、之前幾句對白和做過的選擇。在標題介面也能讀。讀劇情檔時會快進到存檔的那一句，等幾秒即可。不能在戰鬥中存檔。
- **回退到判定前**：劇情裡每次分支判斷、條件檢查、擲骰判定時，自動記下它前一句台詞或選項。看到判定條件後按 F4 回到那一句，用 F9 調好數值再往下點，判定會按新數值重新計算；連按繼續往前退，最多保留最近 3 個判定點。只存在記憶體裡，切場景、進戰鬥後清空。

  <img src="media/anytime-save.webp" width="640" alt="隨時存檔頁：全部隨時存檔，可讀取、寫備註、刪除">

- **新版存檔、讀檔介面**（預設開，設定頁「存檔」可換回原版）：左邊列表，每條有心上人頭像、遊戲日期、存檔時間、備註，旁邊有「刪除」；右邊詳情欄是心上人立繪、存檔類型和時間、讀檔後頭幾句對白，備註框點進去直接寫，按 Enter 儲存。讀檔頁分「手動存檔」「自動存檔」兩頁：手動存檔頁最上面是「開始新遊戲」（用第一個空欄位），自動存檔頁最上面是當前進度（「繼續遊戲」讀的那個），下面按劇情、養成、戰鬥列出全部舊檔。手把 LB / RB 切換兩頁。

  <img src="media/save-browser.webp" width="640" alt="新版讀檔介面：左邊存檔列表帶心上人頭像和備註，右邊心上人立繪和讀檔後的對白">

- **手動存檔 100 個欄位**（原版 20 個）。
- **傳奇欄位 5 頁**（原版 1 頁 12 個，設定頁可改）：儲存傳奇和圖鑑的傳奇介面下方有翻頁按鈕，儲存時自動翻到第一個有空位的頁。
- **存檔備註**：新版介面在右邊的備註框裡直接寫；用原版介面時，選中存檔後按 F8 寫備註（按鍵可在設定頁改），顯示在存檔欄下方，隨 Steam 雲存檔同步。從 LOM_SaveSlotExpander 換過來的會自動匯入原來的備註。
- **自動存檔歷史**：養成、劇情、戰鬥三類自動存檔各多留 5 個舊檔，新版介面裡直接列在自動存檔頁；原版介面在自動存檔卡片右側用 ▲ / ▼ 切換。

### 養成與戰鬥

- **設定頁（F8）**「養成」「戰鬥」兩組裡的開關：
  - 突破屬性上限（預設關）：體力、內力、心相等原本最高 100 的屬性上限改成 9999
  - 無限修煉次數（武學點補滿）
  - 無限鍛造、煉丹次數，不消耗銀兩
  - 決鬥中無敵、決鬥中造成傷害為 0
  - 團戰我方不受傷、團戰絕招無冷卻
  - 遊戲倍速 1x / 2x / 3x / 5x
  - 彈珠小遊戲裡直接設定總分、得分倍率
  - 天命點在 F9 數值頁裡改

- **空過**：養成介面、留學地圖按 ESC，選單裡有「空過」，消耗 1 次行動、不觸發任何事件。
- **直接獲勝**：決鬥、團戰中按 ESC，選單裡有「直接獲勝」。
- **流程提速**：切場景、讀檔、快進劇情更快，回想（對話記錄）不再每句話重排一次；數值變化後的停頓從 0.5 秒縮到 0.2 秒，沒顯示的變化不停頓；養成地圖上行動後的等待和轉場快 3 倍。
- **視窗不透明度**（設定頁「咖啡伴侶」）：咖啡伴侶視窗的底色可以調透明（0.3～1），透過視窗看得到遊戲畫面，文字和按鈕不變。
- **視窗字體**（設定頁「咖啡伴侶」）：咖啡伴侶視窗和本 Mod 的各種小窗、提示用思源宋體（遊戲對話的字體，預設）或微軟雅黑。
- **後台繼續執行**（預設開，設定頁可關）：切到別的視窗時遊戲不暫停，背景音樂也不停。
- **更新內容、檢查新版本**（預設開，設定頁可關）：咖啡伴侶視窗右上角顯示當前版本，點開能看每一版更新了什麼。啟動遊戲時在後台連線問一次 GitHub 最新版本號（只讀，幾 KB，不發送任何遊戲資訊），有新版就在右上角用紅字提示，不彈窗；連不上 GitHub 就什麼都不顯示。
- **開遊戲更快**（預設開，設定頁可關）：標題畫面「啟程」等按鈕浮現的開場動畫加快 6 倍。開頭的兩張 Logo 由安裝器跳過（勾選「跳過遊戲開頭Logo」，預設勾選；它會改遊戲設定檔裡的一個開關，原檔案備份為 `globalgamemanagers.lom-original`，遊戲更新或 Steam 驗證檔案後重新執行一次安裝器即可）。
- **決鬥回合間等待縮短**：身上狀態（buff）越多，回合之間原本要乾等越久；現在空等的步驟直接跳過，效果、數值和結算順序不變。
- **決鬥敵方行動預測**（預設關，設定頁「戰鬥」打開）：決鬥選招時，螢幕右邊顯示敵方這回合預選的招式（嘴攻、捅人、暗器、備揍、絕招）；敵方可能看你的出招臨場改招時標出「可能臨場應變」。
- **技能表全顯示**（預設開，設定頁「戰鬥」可關）：戰鬥時左上角我方的「技能、特殊」列表太長、會壓到血條時，自動分成幾列（先填滿左邊再填下一列）；放得下時和原版一樣。
- **養成行動點**（設定頁）：正常 / 不消耗 / 每旬 N 點（N 在設定頁裡設 1～5）。不消耗時行動點扣到 1 不再扣，用「空過」結束本旬；每旬 N 點時每旬固定 N 次行動。有的選項要「剩餘行動點大於 2」才出現，選每旬 3 點以上，旬初就能觸發。
  > ⚠️ 這兩個模式可能讓部分劇情不觸發或提前觸發，還可能有 bug 卡掉關鍵主線，後面的劇情接不上，整個存檔等於廢了。我們一直在測試和修復，但不能保證完全沒問題，請謹慎使用，多存檔。
- **四師兄售賣全部物品**（預設關，在「設定」頁打開）：商店裡加入所有沒擁有的書籍、雜物、特殊物品；不賣《證類本草》（提前買會導致六月後山事件出 bug）。
- **講經堂**：全部解鎖顯示。

### F9 數值面板

按 F9 打開咖啡伴侶視窗的「數值」頁，一頁裡分幾段：角色數值、武功與學識、門派、其他數值（行動次數、防禦、暴擊、累計點數等）、好感、天賦（全部）、功法修煉點數、鍛造與煉丹開發點數、設施等級、書籍、物品、旗標。

- **書籍、物品**直接改數量，改成幾背包裡就有幾，不用去四師兄商店買；從沒有到有時，和在商店買到一樣推進相關任務。《證類本草》等幾本會標「慎用」，滑鼠停上去看原因。

- 每行寫著當前值（加成和心上人是誰寫在後面），可以加減，也可以在輸入框裡填數字點「設定」。
- **功法修煉、鍛造與煉丹**改的是本層點數，加滿就升一層（和在修煉、開發介面升級一樣加上加成、改相關旗標，只是不花修煉次數和銀兩），多的點數算到下一層。只能升不能降（遊戲沒有撤回加成的辦法）。
- **心相鎖**：「心相」一行加減按鈕前面有個鎖，鎖上後劇情、選項、修煉等對心相的增減都不生效，這一頁的加減、設定照常能改；重啟遊戲、讀檔會自動解鎖。
- **稱號**：從遊戲的全部稱號裡點一個換上，或者寫一個自訂稱號（對話框名字上方、人物介紹、屬性頁都顯示它，對所有存檔生效，清除後恢復遊戲原本的稱號）。
- **好感**列出遊戲裡所有人，原版測試面板沒有的龍淵、石公遠、孟珙等都在。
- **旗標**一千多面全都在，分成門派好感、人物、六道、劇情、事件與支線、對話選項、戰鬥、養成與設施、其他幾類，點哪類看哪類；也能按編號或中文說明搜（如「孟仙謠」「好感」「神兵帖」），分頁顯示，滑鼠停在名字上看完整說明。
- **反查**：旗標、書籍、物品的名字和說明都能點，點開列出它在哪些劇情裡被改動（設成多少、加減、獲得、失去）、在哪些劇情裡被判定（分支判斷、選項條件、任務觸發條件），每處寫明是主線還是支線、任務名、時間、地點和怎麼走到，點「看劇情圖」跳過去。商店、彈珠、團戰掉落這些不經過劇本的找不到。
- 搜尋框下面一排是分組，點哪組看哪組；在搜尋框裡輸入時，所有分組一起搜。

<img src="media/stats.webp" width="640" alt="數值頁：角色數值、武功、門派、稱號、好感、功法等分組，都能加減或直接設定">

亂改數值、旗標可能讓劇情出錯，改之前先存檔。

### 其他

- **手把支援**：咖啡伴侶視窗可以全程用手把操作（搜尋框、數字輸入框打字仍要鍵盤）。按下左搖桿（L3）開關咖啡伴侶視窗，視窗裡左搖桿或十字鍵移動指標、A 點擊、右搖桿捲動、LB / RB 切頁、B 關閉，視窗開著時遊戲不響應手把；PS、Switch 手把的提示顯示對應的鍵名（× / ○、L1 / R1 等）。骰子選線（十字鍵或左搖桿切換，A 確認）、空過、直接獲勝、新版存檔介面、隨機事件自選也都能用手把。
- **匯出診斷**：遊戲 ESC →「環境設定」→「匯出診斷」，把記錄檔、設定、插件清單打包到桌面（不含存檔）。安裝器裡也有同樣的按鈕，Mod 沒載入時用它，還會檢查 BepInEx 是否完整。
- **衝突檢測**：裝了會衝突的舊 Mod 時，啟動幾秒後自動打開設定頁，在最上面用紅字提示是哪個。和別的 Mod 快捷鍵撞了，會自動把本 Mod 的那個熱鍵讓出去（見常見問題）。
- **深色模式**：設定頁「咖啡伴侶」組的「視窗配色」可選淺色（宣紙底，預設）、深色（墨色底）、跟隨系統（Windows 的應用模式）。
- **匯出傳奇**：遊戲「狀態 → 傳奇」面板裡多了「匯出傳奇」按鈕，把這一局還沒完結的傳奇匯出成桌面上的 txt 並打開。原版要走到結局、存進傳奇欄才能匯出。
- **多語言**：咖啡伴侶視窗、各種小窗和提示跟著遊戲語言顯示簡體、繁體或韓語；裝了[日語補丁](https://dlaqe2334.github.io/LOM-JPMOD/)時顯示日語。也可以在「設定」頁最上面的「介面語言」自己選。韓語、日語目前翻譯了介面上的常用文字，其餘仍是中文。安裝器跟著 Windows 的顯示語言顯示簡體、繁體、英語、日語或韓語；更新內容從 2.7.0 起有英語、日語、韓語版。
- **全部簡體顯示**：選項結果、事件名、旗標名等遊戲資料都轉成簡體（遊戲是繁體時轉成繁體）。
- **放大對白文字**：「設定」頁的「對白文字大小」改成 120、140 等，劇情對白框裡的字按比例放大，介面不變。
- **防誤觸**：點 Mod 的視窗時不會點到下面的遊戲介面，在 Mod 的輸入框裡打字也不會觸發遊戲快捷鍵。

## 常見問題

**遇到 bug 怎麼辦？** 先重新執行一次安裝器，確認已是最新版。還有問題的話，用「匯出診斷」把桌面上生成的壓縮包發到 [QQ 群](https://qm.qq.com/q/22cO11mHBq)或 [Issues](https://github.com/kevinnie2003/LOMAssistant/issues)，並說明是怎麼出現的。

**裝了沒反應？** 從系統匣完全退出 Steam 再打開遊戲。還不行就用安裝器裡的「匯出診斷」看看缺了什麼。

**遊戲放在中文路徑下？** 遊戲資料夾的路徑裡有中文等非英文字元時，BepInEx 會載入失敗，Mod 不生效（安裝器會用紅字提醒）。把整個遊戲資料夾移到只有英文、數字的路徑下（比如 `D:\Games\LegendOfMortal`；Steam 版在庫裡右鍵活俠傳 → 內容 → 已安裝的檔案 → 移動安裝資料夾），再執行一次安裝器。

**選項結果不顯示、骰子不能自選？** 和舊版骰子大師、多功能 Mod 衝突，用安裝器會自動處理，手動安裝請刪掉 `BepInEx\plugins` 裡的舊 Mod。

**能和立繪替換 Mod「邪神認知污染ON」一起用嗎？** 能。它是 BepInEx 5 的插件，本 Mod 會幫它載入起來。只裝它的「1_必裝_插件」，**不要**裝它的「2_只有沒裝過BepInEx才裝」（裝了會把 BepInEx 5 混進來，本 Mod 起不來；真裝了就重新執行一次本 Mod 的安裝器，會自動清掉）。快捷鍵撞了的處理見下一條。

**能和「劇情隨行」一起用嗎？** 能。xiaozhanshang 的 [劇情隨行](https://github.com/xiaozhanshang/MortalStoryWorkbench) 可以和本 Mod 同時安裝：兩邊重疊的功能自動用本 Mod 的，快捷鍵撞了的處理見下一條。

**和別的 Mod 快捷鍵撞了？** 本 Mod 識別到別的 Mod（日語補丁、邪神認知污染ON、劇情隨行，以及在自己設定檔裡設了快捷鍵的 Mod）佔著同一個鍵時，會把本 Mod 的那個熱鍵改成不綁定，在設定頁最上面提示一次。之後可以按 Tab 打開視窗再點對應的頁，或在設定頁「熱鍵」裡另綁別的鍵；每個熱鍵也都能手動設成「不綁定」。

**Linux / Steam Deck？** 手動安裝後，在 Steam 啟動選項裡加 `WINEDLLOVERRIDES="winhttp=n,b" %command%`。

## 開發

想自己改程式碼、或者想確認安裝包和源碼一致的話，可以自己編譯。需要 .NET 8 SDK 和裝好本 Mod 的遊戲資料夾（編譯時直接引用遊戲和 BepInEx 的組件，倉庫裡沒有任何遊戲檔案）：

編譯 Mod（會直接裝進遊戲資料夾）：

```bash
GAME="D:/Steam/steamapps/common/LegendOfMortal" DOTNET=/path/to/dotnet ./build.sh
```

編譯一鍵安裝器：

```bash
DOTNET=/path/to/dotnet ./Installer/build-installer.sh
```

| 目錄 | 內容 |
|---|---|
| `LOMAssistant/` | 插件入口、記錄檔、診斷、選項提示等 |
| `LOMAssistant.Config/` | 設定項 |
| `LOMAssistant.Features.*` | 各功能（`Extras` 是本專案新增的，`AnytimeSave` 是隨時存檔） |
| `Installer/` | 一鍵安裝器 |
| `tools/anytime-contract/` | 遊戲更新後重新生成隨時存檔的兼容契約 |
| `tools/bepinex-patch/` | 給打包的 BepInEx 打補丁：修復遊戲裝在中文路徑下 BepInEx 啟動失敗 |
